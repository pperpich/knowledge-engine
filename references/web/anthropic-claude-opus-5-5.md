# Claude Opus 5.5

## Annotation

Anthropic's launch page for Claude Opus 5.5, covering pricing, speed, availability, safety claims, and benchmark results.

## Relevant evidence

Anthropic lists $4/M input, $20/M output, and $0.20/M cache-read pricing for Opus 5.5, versus $5/$25/$0.50 for Opus 5. It reports roughly 40% lower typical-workload cost and more than 30% faster output. Benchmark and efficiency claims are vendor-reported unless the page explicitly attributes a run to an external benchmark operator.
