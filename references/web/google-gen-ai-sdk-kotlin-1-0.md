# Announcing the Google Gen AI SDK for Kotlin 1.0

## Annotation

First-party Google Cloud announcement for the 1.0 Kotlin Multiplatform SDK for Gemini and Google's enterprise Gemini agent platform.

## Relevant evidence

The release targets Android and JVM, provides Coroutines and Flow streaming, and exposes a unified client surface for the Gemini Developer API and enterprise platform. The announcement also demonstrates chat state, grounding metadata, structured function calling, multimodal generation, and Gemini Live.
