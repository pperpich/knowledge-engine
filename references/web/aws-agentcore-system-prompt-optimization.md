# Optimizing agent system prompts with Amazon Bedrock AgentCore

## Annotation

First-party technical description of AgentCore optimization's trace-to-change workflow for agent system prompts.

## Relevant evidence

AWS describes using production traces to propose configuration changes, validating candidates with offline batch evaluation and online A/B testing, and promoting winning configurations. The post also describes reflector-based system-prompt optimization. Benchmark claims are vendor-reported and should not be treated as independent evidence.
