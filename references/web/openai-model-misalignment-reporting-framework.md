# Our framework for reporting model misalignment

## Annotation

OpenAI's first-party framework for tracking, investigating, and disclosing unexpected or concerning model behavior.

## Relevant evidence

The framework describes which misalignment examples OpenAI intends to report and a structured disclosure process. It is a vendor-defined reporting framework, not an independent safety standard or evidence that reporting prevents future incidents.
