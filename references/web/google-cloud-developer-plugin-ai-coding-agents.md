# Introducing the Google Cloud Developer Plugin for AI Coding Agents

## Annotation

First-party Google Cloud announcement for the `google-cloud-developer` plugin and its cross-client packaging of Google Cloud skills and MCP configuration.

## Relevant evidence

Google says the plugin packages Cloud-focused skills and guardrails together with configuration for the Developer Knowledge MCP server. The announcement provides installation paths for Antigravity CLI, Claude Code, and Codex CLI and states that the package follows the Agent Plugins specification.
