# GitLab scales agentic AI across trusted software delivery workflows

## Annotation

GitLab's first-party release announcement for agentic workflow creation, dedicated AI infrastructure, secret controls, and agent-assisted SAST remediation in GitLab 19.3.

## Relevant evidence

GitLab says Flow Creator Agent is generally available and turns natural-language workflow descriptions into runnable custom flows. The same release announces Dedicated AI Gateway general availability, Secrets Manager in limited availability, and beta bulk SAST false-positive detection plus agentic vulnerability resolution. Custom flows can run through scoped service accounts, making agent execution and software-delivery authority part of the same governance surface.
