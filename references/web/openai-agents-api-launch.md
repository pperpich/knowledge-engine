# Introducing the Agents API

## Annotation

First-party OpenAI launch announcement for the public-beta Agents API and its managed agent-harness/runtime surface.

## Relevant evidence

OpenAI describes a managed Codex-derived harness in which developers specify a model, tools, environment, and input. The launch documents OpenAI-hosted, developer-hosted, and supported partner compute; automatic context compaction; tool search and programmatic tool calling; MCP support; parallel subagents; availability to all developers in public beta; and no separate Agents API fee beyond model and tool usage. The page's customer-reported performance anecdotes are not treated as independent benchmark evidence.
