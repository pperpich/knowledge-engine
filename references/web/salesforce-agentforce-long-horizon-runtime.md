# Salesforce Expands Agentforce With a New Portfolio of AI Agents Built for High-Value Work

## Annotation

Salesforce's product announcement describing Agentforce's long-horizon runtime and associated memory, durable execution, and steering capabilities.

## Relevant evidence

Salesforce says its new long-horizon runtime can pursue goals across days and weeks using memory to preserve context and progress, durable execution to resume or course-correct plans, and dynamic steering based on user feedback. Hunter is the first agent on the runtime; broader custom long-horizon-agent support is described as future availability, so that portion should not be treated as generally available.
