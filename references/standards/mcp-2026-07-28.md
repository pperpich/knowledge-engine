# MCP 2026-07-28

## Annotation

Maintainer-authored release description for the MCP 2026-07-28 protocol revision, covering the stateless core, extensions, authorization changes, lifecycle governance, and migration implications.

## Relevant evidence

The revision removes the initialization handshake and protocol-level HTTP session, introduces first-class extensions including Tasks and MCP Apps, strengthens authorization alignment, and requires conformance scenarios before Standards Track proposals can become final.
