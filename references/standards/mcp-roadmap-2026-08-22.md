# The New MCP Roadmap

## Annotation

Maintainer-authored MCP roadmap for work targeting the next specification release and beyond. It is directional rather than a record of already-shipped protocol behavior.

## Relevant evidence

The roadmap elevates server-initiated agentic messaging, workload-agent identity and delegation, and improved tool primitives to active priorities. It describes planned work on webhooks and channels, Tasks maturation, DPoP and workload identity/token exchange, a clearer tool-result contract, and progressive tool discovery for large tool catalogs.
