# Retrieval-Driven Memory Reconsolidation for Long-Term LLM Agents

## Annotation

Original REALM preprint proposing a long-term agent-memory lifecycle in which retrieval feedback drives subsequent memory reorganization.

## Relevant evidence

The authors describe a heterogeneous cognitive graph, adaptively composed graph-search operations, and retrieval-driven reconsolidation. They report 75.97% accuracy on LoCoMo and 65.11% on LongMemEval, 7.17 and 1.31 points above their strongest baselines respectively. These are author-reported preprint results for the complete system; they do not isolate relationship-weight reconsolidation from the other architectural components.
