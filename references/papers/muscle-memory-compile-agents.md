# Muscle Memory for Agents: Compile not Merely Retrieve

## Annotation

Recent preprint proposing a personalization-memory paradigm in which recurring user intent is compiled into purpose-built specialist agents rather than always retrieved as context for a general-purpose orchestrator.

## Relevant evidence

The authors describe a Harvest → Analyze → Augment → Evaluate pipeline that mines interaction history, separates behavioral from task patterns, builds quality-gated specialists, and uses two-stage trigger matching. On 90 held-out scenarios across five personas, a specialist fired in 36 cases and the augmented assistant won 32 of those 36, with a reported +2.05 personalization gain and -0.28 accuracy cost on a 1–4 scale. The study is a preprint and the specialist-fired subset is small, so the result should be treated as an architectural hypothesis rather than a general production guarantee.
