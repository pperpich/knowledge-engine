# Filesystem-Based Memory for LLM Agents

## Annotation

Systematic study of agent-managed filesystem memory, including organization quality, retrieval cost, answer quality, store growth, tool effects, and skill storage.

## Relevant evidence

The authors report that organized stores can substantially reduce retrieval cost at scale, but organization quality degrades for most management agents and does not consistently improve answer quality. Tool choice can reshape the memory store as strongly as changing the model.
