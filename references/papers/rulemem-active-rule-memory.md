# RuleMem: Active Rule Memory for Long-Term Conversational Agents

## Annotation

September 2026 preprint proposing a rule-based memory layer that induces and validates reusable logical relationships from long-term conversation history to guide retrieval and reasoning.

## Relevant evidence

RuleMem constructs natural-language Horn-clause-like rules and validates them with Rule Perplexity Consistency. The authors evaluate on LoCoMo and LongMemEval_s* and report the highest LoCoMo accuracy among 14 compared baselines, 27.47 points above the baseline average (54.3% relative improvement). The result is author-reported and bundles rule induction, validation, retrieval, and reasoning.
