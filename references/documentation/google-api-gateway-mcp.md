# Turn your REST APIs into MCP tools with Google Cloud API Gateway

## Annotation

Google's launch documentation for native MCP serving from API Gateway.

## Relevant evidence

In Public Preview, API Gateway can expose selected OpenAPI 3.x REST operations as MCP tools while reusing the gateway's existing policy path. Tool discovery can be protected separately, and the preview has documented feature limits.
