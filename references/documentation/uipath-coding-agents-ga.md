# Agents - September 2026 release notes

## Annotation

UiPath's first-party release notes for building UiPath agents from external coding agents.

## Relevant evidence

On September 16, UiPath marked building agents with Coding Agents generally available. Its `uipath-agents` skill covers scaffolding, prompt and schema editing, tools, evaluation sets, packaging, and deployment to Orchestrator, and is intended for coding-agent clients including Claude Code, Codex, and Cursor.
