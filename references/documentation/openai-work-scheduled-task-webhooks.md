# Scheduled tasks can respond to app updates and be shared

## Annotation

Official ChatGPT release-note entry for event-triggered and shareable scheduled tasks in ChatGPT Work.

## Relevant evidence

The August 25 release adds webhook-triggered tasks for supported Gmail, Slack, and GitHub pull-request events. Shared tasks create independent copies that recipients can customize and connect to their own apps and permissions; actions that require approval pause for review.
