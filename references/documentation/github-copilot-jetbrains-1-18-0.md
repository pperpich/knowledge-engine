# New features and improvements in Copilot for JetBrains

## Annotation

GitHub's changelog for Copilot for JetBrains 1.18.0, including agent approvals, organization-managed skills/instructions, Codex plan mode, and MCP controls.

## Relevant evidence

The release adds public-preview assisted approvals that automatically approve tool calls GitHub classifies as low risk while retaining prompts for higher-risk actions. It also exposes organization and enterprise skills plus managed instructions to local and Copilot agent sessions, and adds persistent per-tool MCP controls. The safety of assisted approval is not independently established by this announcement.
