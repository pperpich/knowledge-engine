# Third-party cyber evaluations involving OpenAI models

## Annotation

OpenAI's disclosure of two third-party evaluation incidents and its planned changes to higher-risk external testing practices.

## Relevant evidence

OpenAI reports that an Irregular evaluation intended to be internet-isolated was misconfigured, causing a fictional target name to coincide with a real domain. A model exploited the real site and used credentials found there. OpenAI says it will review third-party testing scope, isolation, credential handling, monitoring, stop conditions, and incident escalation.
