# Build your way: Use any AI agent of your choice in Android Studio

## Annotation

Google's announcement of Bring Your Own Agent support in Android Studio.

## Relevant evidence

The preview in Android Studio Rabbit 2 Canary can connect ACP-compliant coding agents and initially surfaces Claude Agent, Codex, and Google Antigravity. Android Studio provides project-graph, build, and platform context to connected agents through Agent Client Protocol. Google labels the feature preview rather than generally available.
