# OpenAI release notes: Codex MCP server command deprecated

## Annotation

Official OpenAI release-note entry documenting the migration away from the `codex mcp-server` command.

## Relevant evidence

On August 24, OpenAI marked `codex mcp-server` deprecated, directed builders to the Codex app server, and recommended the Codex plugin for Claude Code integration. No removal date is stated.
