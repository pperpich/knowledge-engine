# Introducing the Admin plugin for ChatGPT Work and Codex

## Annotation

Official OpenAI announcement for a permission-aware administrative plugin spanning ChatGPT Work and Codex.

## Relevant evidence

The Admin plugin exposes supported workspace analytics and administrative reads and writes, including member and group changes, effective-permission inspection, feature or model access, usage limits, and spending requests. OpenAI states that it operates within each user's existing role and permissions, honors approval requirements, and can automate recurring checks or route exceptions for review.
