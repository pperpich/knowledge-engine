# Grounding with Parallel Web Search

## Annotation

Official Google announcement for native Parallel Web Search grounding in Gemini Enterprise Agent Platform.

## Relevant evidence

The integration provides structured real-time web results with citation annotations. Google states that customers may programmatically call, extract, cache, and post-process the grounded results, including passing them to other models, subject to the service terms and configuration.
