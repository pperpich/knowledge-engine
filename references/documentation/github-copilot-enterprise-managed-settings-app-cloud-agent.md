# Enterprise managed settings for the Copilot app and cloud agent

## Annotation

Official GitHub changelog describing expansion of enterprise-managed settings across additional Copilot clients.

## Relevant evidence

The Copilot app and cloud agent now enforce centrally managed plugin and marketplace controls. Interactive clients also enforce bypass-prompt settings, while managed values take precedence over user configuration.
