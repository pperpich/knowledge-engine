# Content exclusions generally available in Copilot app and CLI

## Annotation

GitHub's first-party announcement extending centrally configured content-exclusion policy to Copilot's app and CLI agent surfaces.

## Relevant evidence

GitHub states that the Copilot app and Copilot CLI now respect content-exclusion policies configured by enterprise, organization, and repository administrators, and excluded files are not used as Copilot context. The capability is generally available for Copilot Business and Enterprise.
