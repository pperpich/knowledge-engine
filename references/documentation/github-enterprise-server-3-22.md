# GitHub Enterprise Server 3.22 is now generally available

## Annotation

First-party GitHub release announcement for GHES 3.22. It is the canonical source for the release's disconnected and air-gapped Copilot CLI deployment capability and its technical-preview status.

## Relevant evidence

GitHub states that GHES 3.22 is generally available. Administrators can configure a model provider in GHES so enterprise users can use Copilot CLI with GHES credentials in environments without connectivity to GitHub Cloud. GitHub labels this Copilot CLI capability a technical preview and says it is subject to change.
