# Configure cost and quality in Copilot auto model selection

## Annotation

GitHub's changelog entry for user-selectable optimization tiers in Copilot's automatic model router.

## Relevant evidence

GitHub says Copilot Auto now exposes efficiency, balance, and intelligence tiers. The tiers use the same available model set but change how Auto weighs cost, quality, and response time for each prompt. The rollout covers VS Code, Copilot CLI, and the GitHub Copilot app, with billing based on the model actually selected.
