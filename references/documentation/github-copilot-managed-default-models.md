# Enterprise-managed settings support any default model

## Annotation

GitHub's first-party announcement for centrally managed default-model selection across Copilot surfaces, including team-specific overrides.

## Relevant evidence

GitHub says enterprises can set a preferred Copilot model as the default for new conversations and optionally mark the model setting overridable so enterprise teams can choose a different default through team mappings. The setting is generally available for Copilot Business and Enterprise in the Copilot app, Copilot CLI, and Visual Studio Code.
