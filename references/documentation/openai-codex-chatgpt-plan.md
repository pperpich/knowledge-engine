# Using Codex with your ChatGPT plan

## Annotation

First-party Codex availability and workspace-control documentation for users who authenticate Codex with ChatGPT.

## Relevant evidence

OpenAI states that GPT-5.4 and GPT-5.4 mini stop being available in Codex for ChatGPT-authenticated users on August 31, 2026, with GPT-5.6 Terra and GPT-5.6 Luna named as replacements. OpenAI advises updating workspace defaults, saved model settings, managed configurations, and automations. The change does not apply to the OpenAI API or Codex sessions using the user's own API key.
