# Importing and syncing plugin marketplaces from GitHub

## Annotation

OpenAI documentation for centrally importing plugin marketplaces from public or private GitHub repositories into managed workspaces and keeping them synchronized.

## Relevant evidence

Admins can import supported marketplace manifests from GitHub, including Codex and Claude-compatible formats. New marketplaces enable daily sync by default, while workspace installation policy, app access, and authentication remain independently enforced. Sync can add new plugins automatically, so repository review remains part of the operational trust boundary.
