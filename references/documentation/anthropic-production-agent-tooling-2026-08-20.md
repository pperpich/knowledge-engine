# Build production agents with computer use, the Skills API, and the Files API

## Annotation

Anthropic's first-party announcement describing generally available computer use, Skills API, and Files API capabilities on Claude Platform, plus a browser-use tool for structured page interaction.

## Relevant evidence

The announcement describes computer use that can perform multiple actions per turn, reusable versioned skill bundles that execute in Claude's code-execution sandbox, reusable file storage addressed by file ID, and browser interaction through page structure and elements. These capabilities separate agent behavior, artifacts, and software interaction into explicit platform primitives.
