# Build more natural voice experiences with GPT-Live-1 in the API

## Annotation

OpenAI's launch documentation for GPT-Live-1, covering the full-duplex voice architecture, backend reasoning delegation, evaluations, pricing, and API availability.

## Relevant evidence

OpenAI says GPT-Live-1 listens and speaks concurrently in one voice model, can delegate deeper reasoning and tool work to a backend text model, and is available in the API at $0.05 per minute for the front-end voice layer. OpenAI reports a 30-percentage-point Full Duplex Bench improvement over GPT-Realtime-2.1; this is vendor-reported evaluation evidence.
