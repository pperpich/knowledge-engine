# Dedicated Copilot app access policy

## Annotation

Official GitHub changelog for independent enterprise and organization access control for the Copilot desktop app.

## Relevant evidence

The Copilot app no longer inherits access from the Copilot CLI policy. Administrators can enable it everywhere, disable it everywhere, or delegate the choice to organizations while preserving pull-request-based review and audit history.
