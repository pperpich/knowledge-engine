# ChatGPT Release Notes

## Annotation

Mutable OpenAI product release-notes page, accessed September 10, 2026 for the September 9 Library sharing update.

## Relevant evidence

OpenAI says ChatGPT Library can now share files and folders with specific people or a workspace, assign Viewer or Editor access, and expose shared items through Shared with me for use in conversations. The notes also specify ownership behavior: files uploaded to a shared folder remain in that folder if the uploader later loses access. The notes do not claim an API, retrieval-quality improvement, or citation/provenance guarantee.
