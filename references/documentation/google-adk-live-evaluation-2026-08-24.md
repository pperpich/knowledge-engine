# How to Evaluate Live & Voice Agents in ADK

## Annotation

Official Google guidance announcing native live and voice-agent evaluation in ADK.

## Relevant evidence

ADK can drive live agents with simulated users that emit audio, score multi-turn trajectories and tool executions with configured rubrics, inspect transcripts and audio in ADK Web, and run the same evaluations from the CLI or programmatically for CI.
