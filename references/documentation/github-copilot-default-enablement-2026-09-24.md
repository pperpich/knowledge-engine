# Default Enablement of Copilot Features for Copilot Business and Enterprise

## Annotation

GitHub's changelog for a new organization-level default policy for eligible generally available Copilot capabilities.

## Relevant evidence

The policy includes eligible feature settings, Copilot Code Review, and MCP-server settings. GitHub says it takes effect October 22, 2026, preserves explicit prior choices, and leaves preview features opt-in.
