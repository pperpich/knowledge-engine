# GitHub Copilot weekly releases — September 14

## Annotation

First-party GitHub changelog summarizing Copilot changes released or rolling out during the week of September 14, 2026.

## Relevant evidence

GitHub reports that Copilot code review now carries findings across subsequent reviews, auto-resolves addressed findings, and can use shell tools for validation. The Copilot app adds a Sentry canvas that brings crash reports, stack traces, and related context into an investigate/validate/prepare-PR workflow. VS Code 1.138 support lets Agents-window sessions run inside local Dev Containers with project tools and dependencies; rollout is gradual and requires Docker plus a supported Dev Container configuration.
