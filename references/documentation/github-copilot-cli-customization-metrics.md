# Agentic CLI customizations now in the usage metrics API

## Annotation

First-party GitHub changelog for organization and enterprise telemetry covering Copilot CLI skills, custom agents, MCP servers, slash commands, and plugins.

## Relevant evidence

GitHub added top-use and distinct-use fields for agentic customizations. MCP interaction counts represent connection or reconnection attempts rather than tool invocations, and customer-defined names are grouped for privacy.
