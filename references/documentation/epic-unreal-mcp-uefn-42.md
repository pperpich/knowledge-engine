# 42.00 Fortnite Ecosystem Updates and Release Notes

## Annotation

Epic Games' official release notes introducing Unreal MCP support inside Unreal Editor for Fortnite (UEFN).

## Relevant evidence

UEFN now embeds a local MCP server that can connect supporting agentic coding tools such as Claude Code, Codex, and Cursor. Epic documents toolsets for writing and compiling Verse, placing and configuring devices, working with Scene Graph and UMG UI, and running play sessions while keeping resulting project state editable in UEFN.
