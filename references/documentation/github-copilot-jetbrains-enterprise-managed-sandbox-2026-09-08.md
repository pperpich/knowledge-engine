# Enterprise-managed sandbox in Copilot for JetBrains

## Annotation

First-party GitHub changelog for the September 8, 2026 JetBrains Copilot release. It is the canonical evidence for the enterprise-managed local sandbox controls and their preview status.

## Relevant evidence

GitHub states that enterprise administrators can centrally configure sandbox enablement, filesystem and network access, proxy settings, developer-tool access, and macOS Keychain access. Managed restrictions take precedence over user settings and lock affected IDE controls. The release also adds enterprise policy diagnostics. These sandbox controls are labeled public preview.
