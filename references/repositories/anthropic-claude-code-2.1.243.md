# Claude Code 2.1.243 changelog

## Annotation

Official Claude Code changelog section for version 2.1.243.

## Relevant evidence

Version 2.1.243 adds per-loop usage metrics, configurable model pickers, separate prompt-cache TTL controls for main and subagent conversations, organization-managed model pricing, and model/effort visibility for subagents. It also fixes recovery after dropped remote MCP connections in non-interactive and SDK sessions.
