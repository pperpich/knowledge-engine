# Claude Code Changelog

## Annotation

Maintainer-authored changelog for Claude Code. This reference is intentionally mutable because new releases are prepended to the same canonical file.

## Relevant evidence

Version 2.1.248, published August 27, adds a restricted execution profile, same-machine cross-session messaging across additional providers, per-agent cache TTL controls, and multiple prompt/cache stability fixes. It also reduces the Workflow tool description from roughly 5.7k tokens to about 1k by moving authoring guidance into a bundled skill. Version 2.1.250 contains only unspecified bug fixes and reliability improvements in the changelog.
